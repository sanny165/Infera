# Sample Documents

Drop a few test files here for local testing / demos, e.g.:

- `sample.pdf` — a normal, text-based PDF
- `scanned.pdf` — a scanned/image-only PDF (to exercise the OCR fallback path)
- `sample.jpg` — a photo/screenshot of text (to exercise the image OCR path)

These are placeholders — add your own files here. They are not required for the
app to run; they're just handy for testing the end-to-end pipeline locally.
